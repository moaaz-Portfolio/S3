S3 Sense Studio

حزمة DrWalls المطوّرة لتناسب ESP32-S3 — واجهة عربية وتفليش من المتصفح.

مهم: لا تفلّش ملف `DrWalls.bin` الأصلي الموجود في المشروع القديم على ESP32-S3. كان مبنيًا لهدف ESP32 العادي. هذه الحزمة تبني نسخة S3 على GitHub حتى لا تحتاج تنزيل ESP-IDF بالجيجات.

أول مرة فقط

  1. فك ضغط الملف.
  2. أنشئ مستودعًا جديدًا على GitHub من المتصفح.
  3. ارفع كل محتويات المجلد المفكوك بما فيها `.github/workflows` ثم اضغط Commit.
  4. من تبويب Actions، افتح تشغيل Build S3 Sense for ESP32-S3.
  5. بعد نجاحه، نزّل Artifact اسمه S3-Sense-Flash-Package.

بعد اكتمال البناء

  1. فك ضغط حزمة Artifact.
  2. شغّل Start-Flash.bat.
  3. استخدم Chrome أو Edge، واضغط التفليش واختر COM الخاص باللوحة.
  4. بعد التشغيل، اتصل بشبكة DrWalls-Setup لإعداد الراوتر.

المزايا

  • واجهة عربية تعمل من المتصفح.
  • ضبط حساسية الحركة والوجود والفلترة ومعدل Ping.
  • حفظ الإعدادات في اللوحة، ومعايرة، وإعادة ضبط خط الأساس وWi-Fi.
  • أداة تشخيص متقدمة ورسوم CSI عبر USB Serial.

لن تحتاج تثبيت بيئة التطوير الثقيلة على الكمبيوتر. أول بناء فقط يتم في حساب GitHub، وبعدها تستخدم ملف التفليش الناتج.
