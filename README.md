# S3 Sense Studio — ESP32-S3 Wi-Fi CSI Motion Lab

**واجهة ويب عربية + إعدادات حقيقية للاستشعار + تفليش من المتصفح، من غير تثبيت ESP-IDF على الكمبيوتر.**

> ملاحظة مهمة: ملفات الـ firmware الأصلية داخل DrWalls كانت مبنية لهدف ESP32 العادي، وليست ESP32-S3. لذلك أزلت ملفاتها الثنائية من هذه النسخة حتى لا يحصل تفليش خاطئ. النسخة المخصصة لـ S3 تُبنى آليًا على GitHub Actions، وتُرفق معها حزمة تفليش جاهزة.

## تشغيل النسخة بأقل تنزيلات محلية

1. فك ضغط `S3-Sense-Studio.zip`.
2. أنشئ مستودعًا جديدًا على GitHub من المتصفح.
3. افتح المستودع واختر **Add file → Upload files**، ثم ارفع محتويات المجلد بعد فك الضغط، بما فيها مجلد `.github/workflows`، واعمل Commit.
4. افتح تبويب **Actions**. سيبدأ تشغيل `Build S3 Sense for ESP32-S3` تلقائيًا. البناء وتنزيل مكوّنات Espressif يحصلان على خوادم GitHub، وليس على جهازك.
5. بعد نجاح البناء، افتح نتيجة التشغيل ثم نزّل ملف **S3-Sense-Flash-Package** من قسم Artifacts.
6. فك ضغط الـ Artifact وشغّل `Start-Flash.bat`. ستفتح واجهة التفليش في Chrome أو Edge على جهازك. لا تحتاج Python أو ESP-IDF محليًا.
7. وصل ESP32-S3 بكابل USB يدعم البيانات، واضغط زر التفليش في المتصفح واختر منفذ اللوحة.

إذا فشل البناء، افتح نتيجة تشغيل GitHub Actions واقرأ أول خطأ باللون الأحمر؛ لا تستخدم firmware من مشروع ESP32 عادي بدلًا منه.

## ماذا تحتوي حزمة التفليش التي ينتجها البناء؟

- `Start-Flash.bat` و`serve.ps1`: تشغيل خادم محلي صغير باستخدام PowerShell الموجود في Windows.
- `index.html` و`manifest.json`: واجهة عربية وتفليش خاص بعائلة ESP32-S3 فقط.
- `firmware/merged-firmware.bin`: ملف firmware مدمج جاهز للتفليش من المتصفح.
- `monitor.html`: أداة متقدمة للرسوم البيانية وتشخيص CSI والمعايرة وتعديل إعدادات القنوات عبر USB Serial.

## واجهة الجهاز وإعداداته

بعد توصيل اللوحة بالراوتر، افتح `http://drwalls.local` من جهاز على الشبكة نفسها. توفر الصفحة:

- حساسية كشف الحركة وحساسية الوجود.
- `active_jitter_min` لتقييد الاستجابة للتذبذب المنخفض.
- `active_filter_ms` لفلترة/تثبيت حالة الاستشعار.
- معدل ping للمساعدة في إبقاء عينات CSI متدفقة.
- مدة تثبيت حالة الحركة في الواجهة.
- حفظ الإعدادات في NVS داخل اللوحة.
- إعادة ضبط خط الأساس، بدء/إنهاء/مسح المعايرة، وإعادة إعداد Wi-Fi.

`monitor.html` يحتاج كمبيوترًا وChrome/Edge واتصال USB باللوحة؛ أغلق Arduino Serial Monitor قبل استخدامه. يمكنك تغيير لغته إلى العربية من زر اللغة في أعلى الصفحة.

## المتطلبات والحدود

- حساب GitHub للوصول إلى البناء السحابي.
- Windows وPowerShell وChrome أو Edge للتفليش؛ لا يلزم تثبيت بيئة بناء على الكمبيوتر.
- اتصال إنترنت أثناء البناء السحابي، واتصال بالإنترنت عند فتح صفحة التفليش لأنها تستخدم مكتبة ESP Web Tools من CDN.
- كابل USB يدعم البيانات.
- هذا مشروع تجريبي لكشف تغيّر إشارات Wi-Fi، وليس وسيلة مضمونة لتحديد الأشخاص أو نشاطهم. الأداء يعتمد على الراوتر والمكان والتداخل.

## الأصل والترخيص

هذه النسخة مبنية على كود DrWalls الذي يضيف واجهة إعداد Wi-Fi وخادم الحركة إلى تقنية Espressif ESP-CSI، وتم الاحتفاظ بملف الترخيص الأصلي. راجع `UPSTREAM-NOTES.md` للتفاصيل.
